# LaundryBoo (PHP Native MVC)
1. Salin folder `laundry` ke `htdocs` (XAMPP) / `www` (Laragon).
2. Import `database.sql` (menghapus & membuat ulang tabel).
3. Sesuaikan `config/config.php` (DB, BASE_URL, ASSET_URL).
4. Buka http://localhost/laundry/index.php
Admin: admin@laundry.test / password (segera ganti). Pelanggan: daftar lewat Register.
