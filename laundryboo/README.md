# LaundryBoo - PHP Native MVC + PDO + MySQL
1. Salin folder `laundryboo` ke `C:\laragon\www\`.
2. Start All di Laragon, import `database.sql` (membuat database `laundryboo_db`).
3. Cek `config/config.php` (DB_USER/DB_PASS).
4. Buka http://localhost/laundryboo/index.php  (sesuaikan port, mis. localhost:8080)
