# CleanFast Laundry (PHP Native MVC)
1. Salin folder `laundry` ke `htdocs` (XAMPP) / `www` (Laragon).
2. Import `database.sql` lewat phpMyAdmin.
3. Cek `config/config.php` (DB & BASE_URL).
4. Buka http://localhost/laundry/index.php
